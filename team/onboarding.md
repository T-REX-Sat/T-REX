# Student Onboarding

1. Read `README.md`, the two source PDFs, and `docs/07_open_issues.md`.
2. Install the package and run tests.
3. Select one work package and one reviewer.
4. Reproduce one baseline output before proposing changes.
5. Open an issue with the question, assumptions, deliverable, and acceptance test.
6. Present a five-minute update after two weeks.
