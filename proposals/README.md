# Proposal Development

Program folders are for program-specific framing. The mission baseline remains in the central requirements and architecture documents.

- `astra/`: strategic architecture and Concept Maturity Level products.
- `niac/`: one enabling breakthrough technology.
- `flight_opportunities_techleap/`: one flight-ready demonstration payload.
- `pioneers/`: reduced pathfinder with standalone science.
- `smex/`: more complete initial observatory.
