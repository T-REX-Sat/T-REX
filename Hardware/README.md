# Hardware

**Owners:** Graham & Chicha

**Goal:** Build one operational 0.7-meter, 1.42 GHz radio telescope.

## Path to first light

| Month | Action | Done when... |
|---|---|---|
| **Sep** | Survey the site; assemble dish, mount, and base | Telescope is stable and the site RFI is measured |
| **Oct** | Connect and bench-test the RF chain | Feed → LNA → filter → Bias-T → PlutoSDR passes a known signal |
| **Nov** | Integrate, point, and calibrate | Telescope produces a repeatable sky spectrum |
| **Dec** | Observe first light | Hardware supports one calibrated astronomical observation |

## Build the floor first

| Required | Stretch |
|---|---|
| One working telescope | Second telescope |
| Proven RF chain | Student-built LNA or feed |
| Stable manual pointing | Automated rotor control |
| Safe power and enclosure | Permanent installation |

## Outputs

- Bill of materials with actual costs
- RF-chain and wiring diagram
- Assembly and calibration checklist
- First-light hardware report
